## Duplicate/concurrency controls added

- Reservation and room state mutations lock the reservation/database room rows.
- Multi-room reservation validation checks aggregate room-type capacity.
- Quick booking, room move, stay amendment, cancellation/no-show, deposit, and refund use deterministic request keys or unique audit records.
- Payment Entry uses the existing Hotel ERP Sync Log and unique ERPNext sync key.
- Direct submitted-reservation cancellation is blocked.
- Manual status changes that bypass check-in, check-out, cancellation, or no-show actions are blocked.
